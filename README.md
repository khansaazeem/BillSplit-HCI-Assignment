# Bill Split App – HCI Assignment

## Course
Human-Computer Interaction (HCI)

## Project Overview
This repository contains my Week 1 HCI assignment. I selected a Bill Split application as my case study to understand how Human-Computer Interaction principles can be applied to a real-world mobile application.

The application is designed to help users manage shared expenses, divide bills, and track payments between friends, roommates, or family members.

## Assignment Objectives
- Understand the HCI design life cycle.
- Identify usability issues in an existing application.
- Understand user needs and interface requirements.
- Explore interface design and prototyping using Figma.
- Suggest improvements to user experience.
